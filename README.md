# ಸತ್ಯವೇದ (Sathya Veda App)

ಸತ್ಯವೇದ (Holy Bible) ಎಂದರೇನು ಮತ್ತು ಅದರ ಮಹತ್ವವೇನು ಎಂಬುದನ್ನು ವಿವರಿಸುವ ಒಂದು ಸರಳ ಫ್ಲಟರ್ (Flutter) ಅಪ್ಲಿಕೇಶನ್.

## ವೈಶಿಷ್ಟ್ಯಗಳು (Features)
* ಸತ್ಯವೇದದ ಪರಿಚಯ ಮತ್ತು ಇತಿಹಾಸ.
* ಹಳೆಯ ಒಡಂಬಡಿಕೆ (Old Testament) ಮತ್ತು ಹೊಸ ಒಡಂಬಡಿಕೆಯ (New Testament) ವಿವರಣೆ.
* ಓದಲು ಸುಲಭವಾದ ಸ್ವಚ್ಛ ಮತ್ತು ಸರಳ ವಿನ್ಯಾಸ.
* ಮೊಬೈಲ್, ವೆಬ್ ಮತ್ತು ಡೆಸ್ಕ್‌ಟಾಪ್‌ಗೆ ಹೊಂದುವ (Responsive) ಸ್ಕ್ರೀನ್.

## ತಂತ್ರಜ್ಞಾನ (Tech Stack)
* Flutter
* Dart

## ರನ್ ಮಾಡುವ ವಿಧಾನ (How to run)
ಈ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ರನ್ ಮಾಡಲು ಈ ಕೆಳಗಿನ ಕಮಾಂಡ್ ಬಳಸಿ:
```bash
flutter run
```

## CouldAI ಬಗ್ಗೆ
ಈ ಆ್ಯಪ್ ಅನ್ನು [CouldAI](https://could.ai) ಬಳಸಿ ರಚಿಸಲಾಗಿದೆ. ಇದು ಕ್ರಾಸ್-ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಆ್ಯಪ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವ ಒಂದು AI ಆ್ಯಪ್ ಬಿಲ್ಡರ್ ಆಗಿದ್ದು, ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ನೈಜ ಐಒಎಸ್ (iOS), ಆಂಡ್ರಾಯ್ಡ್ (Android), ವೆಬ್ (Web) ಮತ್ತು ಡೆಸ್ಕ್‌ಟಾಪ್ (Desktop) ಆ್ಯಪ್‌ಗಳಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ. ಇದು ಸ್ವಯಂಚಾಲಿತ AI ಏಜೆಂಟ್‌ಗಳ ಮೂಲಕ ಪ್ರೊಡಕ್ಷನ್-ರೆಡಿ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ವಿನ್ಯಾಸಗೊಳಿಸುತ್ತದೆ, ನಿರ್ಮಿಸುತ್ತದೆ, ಪರೀಕ್ಷಿಸುತ್ತದೆ ಮತ್ತು ನಿಯೋಜಿಸುತ್ತದೆ.
